# Gajananda Adhikari Portfolio Website

This repository contains the source code for a responsive, static landing page designed as a professional portfolio for Gajananda Adhikari. The site showcases key information such as projects, skills, experience, and certifications, and includes features like a light/dark mode toggle and smooth scrolling for enhanced user experience.

## Features

- **Responsive Design:** Optimized for desktop and mobile devices (ideal for Mac and iPhone).
- **Light/Dark Mode Toggle:** Switch seamlessly between light and dark themes.
- **Smooth Scrolling:** Navigate through different sections with a fluid scrolling effect.
- **Content Sections:**
  - **About Me:** Introduction and career goals as a final year IT student.
  - **Projects:** Highlights projects such as COREQ and AnaLUNG.
  - **Skills:** Lists programming, cybersecurity, web development, and soft skills.
  - **Experience:** Details relevant roles and leadership experience.
  - **Certifications & Awards:** Showcases certifications and notable achievements.
  - **Contact:** Provides a way to get in touch via email.
- **Security:** A basic Content Security Policy (CSP) is integrated to enhance security.

## Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**

## Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites

You only need a web browser to view and test the site.

### Installation

1. Clone this repository:
2. Open the index.html file in your preferred browser to view the site locally.
3. For live deployment, you can upload the files to your preferred hosting service (e.g., GitHub Pages, Netlify, or Vercel).


### Customization

-    Light/Dark Mode Toggle: The website features a simple toggle to switch between light and dark modes. You can modify the default mode in index.html by changing the data-theme attribute to either light or dark.
-    Content Updates: You can easily edit the content by updating the HTML structure in the respective sections like About Me, Projects, Skills, etc.
